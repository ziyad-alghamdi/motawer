# مطوّر

مطوّر هو منصة حديثة لتصميم التصورات العقارية، تساعد المستخدم على تحويل معلومات الأرض واحتياجاته السكنية إلى تصور معماري أولي بطريقة بسيطة وسريعة.

## التجربة المباشرة

https://motawer-amber.vercel.app/

## نبذة عن المشروع

يهدف مطوّر إلى تبسيط المراحل الأولى من التخطيط للمشاريع السكنية من خلال تجربة واضحة ومنظمة.

يمكن للمستخدم إدخال أبعاد الأرض، تحديد عدد الأدوار والغرف والمواقف، اختيار المساحات الإضافية، وتحديد مستوى الخصوصية ونوع المطبخ، ثم استعراض أكثر من تصور تصميمي قبل مشاهدة مخطط ثنائي الأبعاد مبدئي.

النسخة الحالية هي نموذج أولي يركز على سهولة الاستخدام، السرعة، وتصميم واجهة نظيفة وبسيطة.

## أهم المميزات

- واجهة استخدام عربية بسيطة وحديثة
- إدخال المدينة وأبعاد الأرض
- تحديد عدد الأدوار
- تحديد عدد غرف النوم
- تحديد عدد مواقف السيارات
- اختيار المساحات والمميزات الإضافية
- اختيار نوع المطبخ
- تحديد مستوى الخصوصية
- أكثر من نمط تصميم
- مخطط 2D مبدئي
- ملخص نهائي للمشروع
- حفظ البيانات محليًا باستخدام `localStorage`
- واجهة متجاوبة مع الجوال والكمبيوتر
- نشر المشروع بشكل مباشر باستخدام Vercel

## أنماط التصميم

يوفر مطوّر حاليًا ثلاثة أنواع من التصاميم المبدئية:

- تصميم يركز على الخصوصية
- تصميم يعتمد على المساحات المفتوحة
- تصميم يركز على أفضل استغلال للمساحة

كل خيار يقدم طريقة مختلفة في توزيع وتنظيم المساحات داخل المشروع.

## تشغيل المشروع محليًا

قم باستنساخ المستودع:

```bash
git clone https://github.com/ziyad-alghamdi/motawer.git
```

انتقل إلى مجلد المشروع:

```bash
cd motawer
```

قم بتثبيت الحزم المطلوبة:

```bash
npm install
```

شغّل خادم التطوير:

```bash
npm run dev
```

ثم افتح:

```text
http://localhost:3000
```

## حالة المشروع

مطوّر حاليًا في مرحلة النموذج الأولي.

المخططات الموجودة في النسخة الحالية هي تصورات بصرية مبدئية وليست مخططات هندسية معتمدة للتنفيذ.

## التطويرات المستقبلية

من التحسينات المخطط لها مستقبلًا:

- تحليل احتياجات المستخدم باستخدام الذكاء الاصطناعي
- إنشاء مخططات ديناميكية بناءً على المدخلات
- تحسين توزيع المساحات بشكل ذكي
- إضافة القيود والاشتراطات المعمارية
- عرض ثلاثي الأبعاد
- لوحة تحكم للمشاريع المحفوظة
- خيارات لتصدير المشروع
- دعم أنواع إضافية من العقارات
